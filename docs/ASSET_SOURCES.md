## Operational-capacity visual policy

The production site does not publish the operational charts collected from the existing Carrd page. Their underlying values may reflect a real operational setting, so the site instead renders a clearly labeled synthetic reconstruction in HTML and CSS. It preserves only the approved analytical pattern: modest differences by weather category and greater constraints on weekends or platelet-heavy schedules.
